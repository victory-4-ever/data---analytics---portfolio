Global Inflation & Cost of Living Analysis

📌 Project Overview

This project analyzes global inflation and cost-of-living data across countries and regions to identify trends, patterns, relationships, and differences in economic conditions.

The analysis uses data cleaning, exploratory data analysis, statistical analysis, and data visualization to transform the dataset into meaningful insights.

🎯 Project Objectives

- Analyze inflation trends across countries and over time.
- Examine cost-of-living patterns across countries and regions.
- Compare selected countries and regions.
- Identify countries with high and low inflation rates.
- Examine regional variations.
- Analyze the relationship between inflation and cost of living.
- Perform correlation and regression analysis.
- Develop interactive visualizations and dashboards.

🗂️ Dataset

Dataset: Global Inflation and Cost of Living Dataset

The dataset contains country-level and regional indicators used to analyze inflation and cost-of-living patterns.
